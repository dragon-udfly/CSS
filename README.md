# CSS Practice & Styling Repository 🎨📐

A comprehensive collection of HTML pages and CSS stylesheets designed to explore core styling concepts, box models, layouts, media queries, and background media assets.

---

## 📂 Repository Structure

```text
CSS/
│
├── src/
│   └── background.jpg      # Static image asset for background styling practice
│
├── Box.html                # HTML document demonstrating the CSS box model
├── background.html         # Page focused on background styling and image properties
├── box-style.css           # Stylesheet rules for box model exercises
├── layout-style.css        # Stylesheet rules for layout positioning and structures
├── layout.html             # HTML layout practice page
├── media-style.css         # Stylesheet containing responsive media query rules
├── media.html              # Responsive design and media query practice page
├── model.html              # Document exploring box model and container structures
├── practice1.html          # Introductory CSS styling practice exercise
└── style-practice1.css     # Stylesheet linked to practice exercises
```

## 🚀 Key Topics & Concepts Covered
1. The CSS Box Model: Exploring margins, borders, padding, and content dimensions (Box.html, model.html, box-style.css).
2. Layouts & Positioning: Structuring elements on a web page using CSS layout techniques (layout.html, layout-style.css).
3. Backgrounds & Assets: Applying colors, gradients, and background images (background.html, src/background.jpg).
4. Responsive Web Design: Implementing media queries to adapt layouts across different screen sizes (media.html, media-style.css).
